# Daily Sales Tracker & Dashboard 🚀

An interactive web application built with **Streamlit** that allows business owners to log their daily sales and instantly see their performance metrics.

## ✨ Features
- **Data Entry:** Simple form to add product name, price, quantity, and date.
- **Auto-Save:** Saves data automatically to a CSV file (`client_daily_sales.csv`).
- **Live Dashboard:** Instantly calculates total revenue and items sold.
- **Visualization:** Generates dynamic bar charts for sales by product.

## 🛠️ Tech Stack
- Python 3.12
- Streamlit
- Pandas

## 🚀 How to Run
1. Install requirements: `pip install streamlit pandas`
2. Run the app: `streamlit run daily_sales_app.py`
